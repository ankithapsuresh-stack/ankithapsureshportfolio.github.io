02 · Projects

Building through practice

PythonFile handlingGUI

Smart File Organizer & Search Tool

Overview. This project aims to simplify file management by organizing files in a selected directory into folders based on file type, including images, documents, audio, videos, archives, and code. It addresses cluttered directories and makes files easier to locate and manage.

Methods. Built with Python and the built-in os and shutil modules. The application accesses directories, retrieves filenames, creates category folders, and moves files based on extensions. Its interface also includes options for searching files, sorting files, viewing statistics, and reviewing activity history.

Results and learning. The tool is designed to reduce manual effort and improve file accessibility. It demonstrates Python programming, directory management, conditionals, loops, functions, and modular problem-solving. Future improvements could include database integration and a more advanced interface.

GNU OctaveMathematical modelling

Solar Irradiance Analysis

Developed a mathematical model to study the relationship between solar-panel tilt angle and estimated irradiance at noon. Applied equations and numerical integration using trapz(), then plotted results to examine how panel orientation affects estimated solar irradiance.

Prototype conceptPython · OpenCV

TB Diagnosis Support App

Proposed a mobile application prototype to analyze microscope images of colourimetric assay results for tuberculosis screening support. Explored RGB and HSV colour analysis, with a planned Flutter interface and Python backend. This is a prototype concept, not a validated diagnostic tool.
